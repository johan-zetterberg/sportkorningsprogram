# \# Sportkörningsprogram

# 

# Detta är ett webbaserat tävlingssystem för sportkörning (combined driving),

# utvecklat för hantering av dressyr, maraton och precision vid tävlingar.

# 

# Systemet är avsett att användas lokalt vid tävling och kan köras offline

# med synkronisering när uppkoppling finns.

# 

# \## Status

# Projektet är under aktiv utveckling.
